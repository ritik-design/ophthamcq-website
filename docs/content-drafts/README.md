# OphthaMCQ publication drafts

These Markdown files are publication-ready editorial handoffs for the theStacc blog pipeline. They are intentionally **not** stored in `src/content/blog`, which is a legacy, unrendered directory in this Astro repository.

Before publishing each article:

1. upload the body and metadata through theStacc;
2. confirm the final slug and canonical URL generated by the platform;
3. add the supplied Article and FAQ structured data through the publishing interface;
4. verify every internal link and the rendered FAQ/MCQ formatting;
5. check the published URL in the sitemap and Search Console.
