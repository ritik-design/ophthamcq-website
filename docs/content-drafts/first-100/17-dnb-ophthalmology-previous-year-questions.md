Previous-year questions repeat concepts more reliably than they repeat wording. The useful question is not “Will this stem come again?” but “Which decision has been tested repeatedly across different clinical contexts?”

## Measure concepts, not memories

Create a table with year, topic, decision, source and error type. Examples of decision labels include “corneal ulcer: investigation choice”, “glaucoma: field defect interpretation” and “retinal detachment: break localisation”. Do not count a recall twice because it appears in two message groups.

| Finding in your log | Revision response |
|---|---|
| Same concept, different vignette | learn the discriminating feature |
| Same image type | practise a spoken description |
| Persistent two-option error | make a one-line comparison card |
| Correct by guess | treat as an error until you can explain it |

Candidate recalls are not official papers. Check uncertain keys against current references and the active [NBEMS](https://natboard.edu.in/) notice. A past-paper trend should guide reading priority, never replace the syllabus.
