## SERP gap and information gain

Available cornea quiz content often provides an image with a one-word answer, or gives a long cornea chapter without testing image interpretation. The page fills the gap with a repeatable image-stem sequence: site → layer → pattern → context → limitation. It also forces classic signs into their proper evidence boundary—for example, a ring infiltrate can support an Acanthamoeba differential but does not establish the diagnosis.

**Differentiation statement:** A source-led, text-first picture-question rehearsal that remains useful while no cleared clinical image set is available, and that teaches candidates to describe before they label.
